Student Performance Analysis
Project Overview

Student Performance Analysis is a data analytics project developed using MS Excel and Power BI to analyze and visualize student academic performance.

The project focuses on analyzing students' marks, grades, attendance, subjects, and overall performance through an interactive Power BI dashboard.

Tools & Technologies
Microsoft Excel – Data preparation, cleaning, calculations, and dataset management
Power BI – Data visualization and interactive dashboard development
Power Query – Data transformation and cleaning
DAX – Calculations and measures
Key Analysis

The dashboard provides insights into:

Total number of students
Overall student performance
Subject-wise performance
Student marks and grades
Attendance analysis
Year-wise student performance
Pass and fail analysis
Grade distribution
Average marks
Performance comparison across subjects
Dashboard Features

The Power BI dashboard includes interactive visuals and filters that allow users to explore student performance based on different academic criteria.

Users can analyze:

Student performance by year
Subject-wise results
Grade distribution
Attendance
Average marks
Pass/fail status
Dataset

The dataset contains student academic information such as:

Student Name
Gender
Year
Subject Marks
Attendance
Total Marks
Average Marks
Grade
Result Status

**Project Workflow
1. Data Preparation

Student data was created and organized using Microsoft Excel.

2. Data Cleaning

The dataset was cleaned and prepared for analysis using Excel and Power Query.

3. Data Transformation

Required columns, calculations, grades, and result categories were prepared for analysis.

4. Dashboard Development

The cleaned dataset was imported into Power BI and an interactive dashboard was created.

5. Data Analysis

Power BI visuals and measures were used to identify patterns in student performance.
